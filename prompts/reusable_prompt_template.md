# Reusable Prompt Templates

Copy a template, fill in the `[BRACKETS]`, and paste it to your AI assistant.

---

## 1. Concept Explainer (IQ note style)

```
Explain [YOUR CONCEPT] in a table view with clear comparison columns.
Use a simple code/file example to walk through each layer.
Save it as a `.md` file inside the `IQ_Notes` folder.
Follow the same visual style as `Source_Code_ByteCODE_Binary_IQ.md` —
breakdown table, example walkthrough, pipeline diagram, and TL;DR.
```

### Filled Example

```
Explain let vs var vs const in a table view with clear comparison columns.
Use a simple code/file example to walk through each layer
(e.g., Chapter_01_JS_Basics/Let_concepts.js).
Save it as a `.md` file inside the `IQ_Notes` folder.
Follow the same visual style as `Source_Code_ByteCODE_Binary_IQ.md` —
breakdown table, example walkthrough, pipeline diagram, and TL;DR.
```

---

## 2. Style Reference

The visual style referenced above lives in:
`IQ_notes/Source_Code_ByteCODE_Binary_IQ.md`

Required sections for every note:
1. **Breakdown table** — clear comparison columns
2. **Example walkthrough** — simple code/file example traced through each layer
3. **Pipeline diagram** — ASCII flow
4. **TL;DR** — short summary

---

## Tips for Getting Better Explanations

| If you want… | Add this to the template |
|---|---|
| Simpler language | "Explain like I am completely new to programming." |
| More depth | "Go deeper into [SUBTOPIC] with extra examples." |
| Practice | "Add 3 practice exercises with solutions." |
| Playwright focus | "Show how [TOPIC] is used in a real Playwright test." |
| Fix my code | Replace the template with: "Fix my code and explain every change you made." |
